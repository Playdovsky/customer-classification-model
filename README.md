## Churned customer classification
Based on the provided customer data, this program teaches models to determine whether customer will become churned.
Churned customer is an individual who stopped purchasing goods, cancels subscription, or terminates their business relationship with a company.
Besides that, this classification may help companies to check what factors are significant for customer churn.

### This program:
* Prepares the data
  * Cleanup
  * Encoding
* Analyzes the data
  * Correlation heatmap
  * Histogram
  * Box plots
* Performs machine learning
  * Decision tree
  * Random forest
  * SVM linear
  * XGBoost
* Performs deep learning
  * Activation: SeLU, Sigmoid
  * Dropout
* Performs XAI SHAP on machine and deep learning models
### Information about data used in this model:
* Ecommerce Customer Behavior Dataset
* 50,000 records (customers)
* 25 columns
* shared by Dhairyajeet Singh on kaggle
* https://www.kaggle.com/datasets/dhairyajeetsingh/ecommerce-customer-behavior-dataset
